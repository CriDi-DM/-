# README — Многоцветный муравей Лэнгтона: вычислительный комплекс

## 1. Суть компьютерной модели

Многоцветный муравей Лэнгтона — клеточный автомат с одним агентом (лекция, разд. 3.6–3.7).
Клетка решётки принимает состояние s ∈ {0, 1, …, q−1} (q — число цветов). На каждом такте
агент: (1) считывает цвет s текущей клетки; (2) поворачивает по команде строки правил
rule[s] ∈ {R — направо, L — налево, F — прямо, U — разворот}; (3) перекрашивает клетку
циклически s → (s+1) mod q; (4) шагает вперёд. Классический муравей — правило `LR` при q=2.

Реализованы: квадратная и гексагональная решётки; открытое поле, отражающие и периодические
(тор) границы; автоматическая классификация режима поведения на 5 классов (разд. 3.7):
1 — ограниченное движение, 2 — периодическое движение, 3 — магистраль,
4 — неограниченный нерегулярный рост (хаос), 5 — симметричный рост.

Скрипт воспроизводит весь цикл исследовательской работы: верификацию среды (правило чётности,
закон N(t)=4^w(t)), точное измерение параметров магистрали, чувствительность к начальным
условиям, полный перебор строк правил (q=2–4), мутации одного символа, сравнение решёток
и типов границ, построение рисунков для отчёта.

## 2. Возможности и ограничения

Возможности:
- две топологии решётки и три типа границ (открытые / отражающие / тор);
- три детектора режимов: локальные окна (квадрат, перекрёстно верифицирован), эталонный
  верификатор (периодичность последовательности направлений + MD5 полного состояния),
  хэш полного состояния (эксперименты с границами);
- произвольные строки правил и начальные поля; воспроизводимость (seed=42 в Серии 2);
- автоматические текстовая сводка, JSON-каталоги правил и 6 рисунков для отчёта.

Ограничения:
- сканер периодов охватывает τ ≤ TAU_MAX и требует «хвост» не короче 3τ после перехода;
  более длинные периоды магистралей не подтверждаются (правило попадает в класс 1/4 с оговоркой);
- точный цикл ограниченных правил ищется хэшем полного состояния только после остановки роста
  области; цикл длиннее горизонта моделирования не обнаруживается (класс 1 — «не обнаружено»,
  а не доказательство апериодичности); то же для коробок при T = BOX_T;
- окрестность агента фиксирована (текущая клетка): типы окрестностей не варьируются,
  вместо этого варьируется топология решётки; один агент (режим нескольких муравьёв не реализован);
- модель детерминирована (случайность только в Серии 2, воспроизводима);
- время счёта: полный прогон (RUN_Q4=True, BOX_T=200000) ≈ 4–6 минут в один поток.

## 3. Инструкция по запуску и параметры

Требования: Python ≥ 3.8, пакеты numpy и matplotlib.
Установка зависимостей:  pip install numpy matplotlib
Запуск всего комплекса:  python All_Langton_Ant.py

Параметры задаются константами в начале файла:

| Константа  | По умолчанию | Назначение                                             |
|------------|--------------|--------------------------------------------------------|
| T_MAIN     | 30000        | горизонт классификации правил (Серии 2–4)              |
| TAU_MAX    | 6000         | предел сканера периодов эталонного верификатора        |
| BOX_T      | 200000       | горизонт экспериментов с границами (Серия 5)           |
| RUN_Q4     | True         | полный перебор q=4 на квадрате (~2 мин); False — пропуск |
| SHOW_PLOTS | True         | показывать окна рисункков в конце работы               |

Быстрая демонстрация (~1 мин): RUN_Q4 = False, BOX_T = 50000.
Запуск отдельного эксперимента: в консоли Python выполнить
    import All_Langton_Ant as m; m.part1()   # доступны part0() … part6()

## 4. Структура входных и выходных данных

Вход: внешних файлов нет. Конфигурация — константы п. 3; правило — строка над алфавитом
{R, L, F, U} длины q (пример: 'LR', 'RLLR'); начальное поле — список пар ((i, j), цвет)
(Серия 2); тип решётки — строка 'square' | 'hex'.

Выход:
- консольный лог, дублируемый в research_summary.txt (все таблицы отчёта);
- catalogs.json — каталоги правил, ключи square_window_q2 / q3 / q4 и hex_verified_q2 / q3;
  запись: {rule, cls, tau, d, t_onset или s0, nvis [, bbox, sym]};
- рисунки (PNG, 150 dpi):
  fig01_parity.png     — поле правила чётности, шаг 50;
  fig02_series1.png    — Серия 1: поле, дистанция, крупный план перехода и магистрали;
  fig03_gallery.png    — галерея режимов (LR, RR, RLLR, RRUL);
  fig04_hex_clouds.png — гексагональная решётка: облака правил LR и RF;
  fig05_box_fields.png — итоговые поля коробок m=30/50/70, отражающие и тор;
  fig06_box_dist.png   — дистанция от старта в коробках m=30 и m=50.

## 5. Интерпретация результатов

- cls — класс режима по разд. 3.7 лекции (см. п. 1).
- tau — период; d — вектор сноса за период: d=(0,0) означает цикл на месте (класс 2),
  d≠0 — магистраль (класс 3); скорость магистрали v = |d|₁ / tau (кл/шаг).
- t_onset и s0 — два операциональных определения момента возникновения режима
  (детектор локальных окон и сканер направлений); для LR: s0 ≈ 9977, t_onset ≈ 10112,
  разность ~135 шагов — время стабилизации локального окружения агента.
- nvis — число посещённых клеток; bbox — площадь ограничивающего прямоугольника;
  t_wall — шаг первого контакта с границей; n_refl — число отражений.
- Чтение графиков: флуктуации дистанции при ограниченном размахе — хаотическая фаза;
  линейный рост — магистраль; насыщение на 0…m в коробке — граничный хаос;
  широкое разреженное «облако» на гексе (fig04) — НЕ магистраль.
- Этalonные значения для самопроверки установки: LR (квадрат): tau=104, d=(2,2),
  v≈0.03846; распределения классов: квадрат q=2 {1:2, 2:7, 3:7}, q=3 {1:9, 2:13, 3:30, 4:12};
  гекс q=2 {1:3, 2:7, 3:5, 4:1}, q=3 {1:21, 2:9, 3:18, 4:16}; мутации: смена класса у 7/12
  (база RLLR) и 6/12 (база LRLR); t_wall(m=30/50/70) = 1403/5439/10837.
- Предостережение: детектор на локальных окнах надёжен только на квадратной решётке
  (перекрёстно верифицирован двумя реализациями). На гексагональной решётке и в коробках
  он даёт артефакты (исторические примеры: ложные tau=88 на гексе и tau=948 в коробках),
  поэтому там применяется только эталонный детектор; расхождения наивной и эталонной
  классификаций приведены в отчёте (раздел «Верификация измерительного инструмента»).
