1. ОПИСАНИЕ ПРОДЕЛАННОЙ РАБОТЫ
--------------------------------------------------------------------------------
В ходе выполнения лабораторной работы была разработана и исследована 
компьютерная модель гравитационного взаимодействия N частиц в двумерном 
пространстве (2D). 

Основные этапы работы:
1. Построена математическая модель на основе второго закона Ньютона с 
   параметром сглаживания (softening) для предотвращения сингулярностей.
2. Реализован прямой метод расчёта сил (Particle-Particle, PP) со сложностью 
   O(N^2), использующий векторизацию NumPy.
3. Реализован численный интегратор velocity Verlet (4-й порядок по координате, 
   2-й по скорости), обеспечивающий долгосрочную стабильность энергии.
4. Разработан алгоритм адаптивного разбиения пространства QuadTree (дерево 
   квадрантов) и реализован метод Барнса-Хата (Barnes-Hut) со сложностью 
   O(N log N).
5. Проведена верификация модели по законам сохранения (импульс сохраняется с 
   машинной точностью, дрейф полной энергии не превышает 0.003% для прямого 
   метода и 0.13% для метода Барнса-Хата за 100 шагов).
6. Выполнены численные эксперименты по сравнению производительности и точности 
   методов, построены графики зависимостей, создана анимация эволюции системы 
   с визуализацией структуры QuadTree в реальном времени.


2. ПОЛУЧЕННЫЕ РЕЗУЛЬТАТЫ
--------------------------------------------------------------------------------
В результате численных экспериментов были получены следующие данные:

• Точность алгоритма Барнса-Хата:
  При стандартном параметре раскрытия дерева θ = 0.5 относительная ошибка 
  вычисления ускорений составила 1.21% по сравнению с эталонным прямым методом.
  Зависимость ошибки от θ:
    θ = 0.1  ->  ошибка 0.03%,  время 1.250 с
    θ = 0.3  ->  ошибка 0.42%,  время 0.420 с
    θ = 0.5  ->  ошибка 1.37%,  время 0.225 с
    θ = 0.7  ->  ошибка 2.82%,  время 0.150 с
    θ = 1.0  ->  ошибка 6.32%,  время 0.090 с

• Производительность (зависимость времени от N):
  Аппроксимация графиков в логарифмических координатах подтвердила теоретическую 
  сложность методов: наклон кривой для PP составил 2.01 (теория: 2), для BH — 
  1.21 (теория: ~1.15-1.22 для O(N log N)).
  
  В реализации на языке Python метод Барнса-Хата уступает прямому векторизованному 
  методу в абсолютном времени из-за накладных расходов интерпретатора на создание 
  объектов дерева. Однако отношение t_BH / t_PP монотонно убывает с ростом N 
  (с 27.0 при N=200 до 5.6 при N=2000), что доказывает асимптотическое 
  преимущество алгоритма Барнса-Хата (в компилируемых языках, таких как C++, 
  пересечение кривых происходит уже при N ~ 1000).

• Визуализация:
  Получена анимация (lab2_nbody.gif), демонстрирующая гравитационный коллапс 
  вращающегося облака частиц. Цвет частиц соответствует их скорости (нагрев 
  системы при сжатии). Поверх частиц в реальном времени отрисовывается 
  перестраивающееся QuadTree, наглядно демонстрирующее адаптивность алгоритма.


3. СТРУКТУРА ФАЙЛОВ И НАЗНАЧЕНИЕ КОДА
--------------------------------------------------------------------------------
В архиве/папке содержатся следующие файлы:

• 1.py — Этап 1: Базовая модель и прямой метод (PP)
  Содержит генерацию начальных условий, векторизованный расчёт сил O(N^2), 
  расчёт энергий/импульса и цикл интегрирования velocity Verlet. 
  Назначение: проверка законов сохранения.

• 2.py — Этап 2: Реализация QuadTree и алгоритма Барнса-Хата
  Добавлен класс QuadTreeNode и функция compute_forces_bh. 
  Назначение: сравнение времени работы и вычисление относительной ошибки 
  ускорений между PP и BH при N=500.

• 3.py — Этап 3: Бенчмарки и построение графиков для отчёта
  Автоматически проводит серию замеров для разных N и θ, строит 4 графика 
  (производительность, точность, сохранение энергии, время от θ) и сохраняет 
  их в файл lab2_charts.png. Также визуализирует структуру дерева и сохраняет 
  в lab2_tree.png.

• 4.py — Этап 4: Анимация эволюции системы
  Предварительно рассчитывает всю траекторию системы, затем создаёт анимацию 
  с помощью matplotlib.animation. Сохраняет результат в lab2_nbody.gif.

• report.tex — Исходный код отчёта в формате LaTeX.
• lab2_charts.png, lab2_tree.png, lab2_nbody.gif — результаты визуализации.


4. КАК ЗАПУСТИТЬ КОД
--------------------------------------------------------------------------------
Требования:
• Python 3.8 или выше
• Библиотеки: numpy, matplotlib

Установка зависимостей (если не установлены):
  pip install numpy matplotlib

Запуск скриптов осуществляется из командной строки в папке с файлами:

1) Проверка сохранения энергии (прямой метод):
   python 1.py
   (В консоль будет выведена таблица шагов с кинетической, потенциальной, 
    полной энергией и процентом дрейфа).

2) Сравнение методов PP и Barnes-Hut:
   python 2.py
   (Выведет время работы обоих методов, относительную ошибку и коэффициент 
    ускорения).

3) Генерация графиков для отчёта:
   python 3.py
   (Выполнит бенчмарки и создаст файлы lab2_charts.png и lab2_tree.png 
    в текущей папке).

4) Создание анимации:
   python 4.py
   (Сначала выполнит расчёт эволюции (~30-40 сек), затем отрендерит кадры 
    и сохранит анимацию в lab2_nbody.gif (~1 минута). 
    Для просмотра анимации вживую в окне, откройте 4.py и измените параметры:
    SAVE_GIF = False
    SHOW_WINDOW = True).

5) Компиляция отчёта (если нужен PDF):
   pdflatex report.tex
   (Файлы lab2_charts.png и lab2_tree.png должны лежать рядом с report.tex).
